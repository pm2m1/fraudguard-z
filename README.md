# FraudGuard Z

**Team INSANES | IBM Z Datathon 2026**

Stateful, network-aware financial fraud detection and
auditable transaction decisioning on IBM LinuxONE.

## Project Goals

- Detect suspicious financial transactions using machine learning.
- Compare transaction-only and recipient-history models.
- Maintain chronological, past-only transaction state.
- Produce auditable ALLOW, REVIEW, and BLOCK decisions.
- Deploy and demonstrate the solution on IBM LinuxONE.

## Dataset

PaySim Synthetic Financial Datasets for Fraud Detection.

Source:
https://www.kaggle.com/datasets/ealaxi/paysim1

The original dataset is not stored in this repository.

## Planned Technology Stack

Python, NumPy, pandas, scikit-learn, Flask, SQLite,
pytest, and IBM LinuxONE.

## Status

Under development for IBM Z Datathon 2026.

## Limitations

PaySim is synthetic. Results do not establish
real-world fraud-detection effectiveness.
